REQUIREMENTS CHECK
------------------
- 4 pages linked from the nav; current page marked with class "active" and aria-current
- Semantic tags: header, nav, main, section, article, aside, footer
- One h1 per page, then h2 / h3
- Contact form: label, text, email, select, textarea, button (required on name and email)
- figure + figcaption on images
- audio element with controls, caption, and text alternative
- Meaningful alt text on every image
- Viewport meta tag on every page
- One external stylesheet: css/style.css
- CSS variables for colors and fonts
- Flexbox (header, nav, footer, help strip) and Grid (cards, gallery, hero, form layout)
- Breakpoints: phone (default), tablet 600px, desktop 1000px
- Hover and focus states on links, buttons, and form fields
